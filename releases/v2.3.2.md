# Manager Board v2.3.2 — Project Publishing Visibility

Manager Board v2.3.2 makes long-running Workfront publication easier to follow
and adds explicit controls for reviewing every task beneath project summary
tasks.

## What’s improved

- Shows live progress while reviewed project changes are rechecked and
  published to Workfront.
- Reports the current publishing phase and completed item count without
  changing which reviewed changes are selected.
- Keeps project task groups collapsed when a project opens.
- Adds separate Expand All Tasks and Collapse All Tasks actions so every nested
  task can be reviewed together and the compact view can be restored easily.
- Preserves the Windows runtime compatibility correction and secure update
  behavior from v2.3.1.

## Safety and continuity

- Manager Board still rechecks Workfront immediately before publishing and
  stops when a reviewed task changed remotely.
- Publishing remains explicitly reviewed and user-confirmed; Manager Board does
  not delete Workfront records.
- Expand and collapse actions change only the current view.
- Schema remains v45.
- Existing Workspace, Vault, Workfront, activation, backup, restore, Local AI,
  updater, public-support, and privacy boundaries remain intact.
- No GGUF model, source code, business data, credentials, diagnostics,
  activation material, or private signing material is included in this public
  release repository.
