# Manager Board v2.5.0 — Local AI File Analysis

Manager Board v2.5.0 adds private, on-device analysis of one supported local
file in normal Local AI Chat while preserving the existing text and image
workflows.

## What’s new

- Browse, paste, or drag and drop one supported document, script, source-code,
  data, configuration, project, infrastructure, or email file into Chat.
- Ask follow-up questions about the attached file without selecting it again.
- Remove the file and continue the same conversation without the attachment.
- Analyze locally extracted text with the existing Qwen model; file analysis
  does not require an `mmproj` vision projector.
- See clear local-processing status, bounded extraction details, and actionable
  errors for unsupported, unreadable, oversized, or truncated files.

## Supported formats

- PDF, DOCX, XLSX/XLSM, PPTX, and EML.
- Plain text, Markdown, CSV/TSV, JSON, XML, YAML, logs, and common source-code,
  script, configuration, project, and infrastructure text files.

## Privacy and safety

- File analysis runs locally inside Manager Board with no AI server, listener,
  service, or child AI process.
- Original file bytes and extracted content remain in the current Chat session
  and are not written to SQLite, backups, exports, or the OneDrive Vault.
- Attached content is treated as untrusted data. Code, links, formulas, macros,
  and email attachments are never executed.
- Manager Board continues to work normally without Local AI, without a model,
  or without a vision projector.
- GGUF models, projectors, and user files are not included in the installer or
  this public repository.
- This release remains schema v45 and preserves the accepted Workspace, Vault,
  Workfront, activation, updater, backup, restore, and privacy boundaries.

## Current limits

- One attached file at a time, up to 10 MiB and 100,000 extracted characters
  before context clipping.
- PDFs require selectable text; scanned pages do not receive OCR.
- Legacy binary Office files, archives, executables, audio, and video are not
  supported.
- Large or complex supported files may be deliberately truncated.
