# Manager Board v2.4.0 — Local AI Vision

Manager Board v2.4.0 adds optional private, on-device single-image analysis to
normal Local AI Chat while preserving every existing text-only workflow.

## What’s new

- Attach, paste, or drag and drop one PNG, JPG, or WebP image into normal Chat.
- Ask follow-up questions about the attached image without selecting it again.
- Remove the image and continue the same conversation in text-only mode.
- Use the existing embedded Qwen 3.5 llama.cpp runtime with a matching,
  user-selected `mmproj` vision projector.
- See clear local-processing status and actionable errors when vision is not
  configured, incompatible, or unavailable.
- Continue using the separate Advanced Model Testing image path for diagnostics.

## Privacy and compatibility

- Image analysis runs locally inside Manager Board with no AI server, listener,
  service, or child AI process.
- Attached image bytes remain in the current Chat session and are not written to
  SQLite, backups, exports, or the OneDrive Vault.
- Manager Board continues to work normally without Local AI, without a model,
  or with a text-only model configuration.
- The GGUF model and matching projector remain optional user-managed files and
  are not included in the installer or this public repository.
- This release remains schema v45 and preserves the accepted Workspace, Vault,
  Workfront, activation, updater, backup, restore, and privacy boundaries.

## Current limits

- One image at a time.
- No OCR or multi-document workflow.
- A projector released for the exact vision model is required.
