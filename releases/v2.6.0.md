# Manager Board v2.6.0 — Reliability and Draft Recovery

Manager Board v2.6.0 protects unfinished editor work and improves responsiveness across everyday manager workflows.

## What's new

- Recover unfinished editor work through durable Workspace drafts, including staged attachments and review evidence selections.
- Preserve meeting drafts after a typing pause and when leaving the editor, with explicit Save continuing to commit the record.
- Load startup screens, Dashboard and People summaries, and Daily Work more efficiently.
- Respond promptly to daily task completion changes while saving them safely.
- Improve operational editor saves and project task paging.
- Apply compatible browser graphics automatically in Windows Remote Desktop, addressing the confirmed screen flicker and typing delay.

## Preserved behavior

The release retains manager-controlled review evidence selection, readable historical evidence, Employee Plan flexibility, and existing manager judgment and privacy boundaries. Core work remains local and usable offline. Optional Local AI models remain separately managed and are never bundled.

## Workspace upgrade

This release upgrades the Workspace from schema 47 to schema 48 for durable drafts and creates a portable backup before migration. Workspace and Vault data remain separate from the replaceable application. An older schema-47 application must not be used to open a migrated Workspace; returning to an earlier application requires an appropriate validated pre-upgrade backup.

## Validation

The complete regression passed 2,627 tests with four warnings. The official build passed 109 release and package checks and all 20 real-model quality cases. The release build requires native runtime and payload audits, trusted signing of the application, native AI runtime, installer components, and final installer, and verification of the exact public asset size and SHA-256 digest. Product-owner installed acceptance is recorded separately from automated checks.
