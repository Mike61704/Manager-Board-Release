# Manager Board v2.5.2 — WorkTango Reporting

Manager Board v2.5.2 makes imported WorkTango recognition easier to understand in Leaderboard and Manager Center reports and adds complete Daily Work import guidance.

## What's new

- See who awarded each qualifying WorkTango recognition in Leaderboard score detail.
- Include the WorkTango sender department when it is available in the imported report.
- Export the same sender attribution in Leaderboard Recognition Evidence.
- Include qualifying WorkTango points awarded to the configured manager in Manager Center reporting, separately from employee Leaderboard scoring.
- Include the manager's WorkTango recognition in Manager Center HTML, CSV, JSON, and XLSX reports.
- Open a dedicated Daily Work Import help article with separate instructions for Ivanti Incidents, Ivanti Tasks, and WorkTango Recognition.

## WorkTango scoring

- Employee Leaderboard scoring continues to count a positive award when the recipient matches an active Manager Board person and the sender is either the configured manager or someone outside the active team.
- Recognition exchanged between active team members does not score.
- WorkTango Admin/system activity, zero-point activity, and unmatched employee recipients do not score.
- Positive awards received by the configured manager are matched through Manager Profile email and reported only in Manager Center.
- WorkTango recognition does not create manual Daily Work, work-item, Auto Impact, duplicate Recognition, or Consistency points.

## Privacy and safety

- Manager Board remains local-first; imported CSV data stays in the selected local Workspace and follows existing backup and restore behavior.
- No WorkTango report, Workspace, Vault, backup, business data, credentials, diagnostics, activation material, source code, private signing material, GGUF model, or projector is included in the installer or this public repository.
- This release retains schema v46 and preserves the accepted Workspace, Vault, Workfront, activation, updater, Local AI, backup, restore, and privacy boundaries.
