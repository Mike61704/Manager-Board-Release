# Manager Board v2.5.1 — WorkTango Recognition

Manager Board v2.5.1 adds reviewed WorkTango recognition import, audit, and Leaderboard scoring while preserving existing Daily Work and recognition workflows.

## What's new

- Import WorkTango Recognitions Report CSV files from the consolidated Daily Work **Import** menu.
- Review matched, eligible, excluded, unmatched, and duplicate rows before saving an import.
- Add qualifying WorkTango awards to the existing Leaderboard **Recognition** score at their imported point value.
- Show qualifying WorkTango evidence on its Daily Work date and in the employee's **Wins / Recognition** preparation card.
- Keep imported Daily Work details collapsed by default with per-card **Show Imported Details** and view-wide **Expand All** / **Collapse All** controls.
- Preserve existing Ivanti incident and task imports in the same consolidated Import menu.

## WorkTango scoring

- A positive award counts when the recipient matches an active Manager Board person and the sender is either the configured manager or someone outside the active team.
- Recognition exchanged between active team members does not score.
- WorkTango Admin/system activity, zero-point activity, and unmatched recipients do not score.
- Excluded rows remain available for audit, and overlapping imports are deduplicated without relying on the recognition URL alone.
- WorkTango recognition does not create manual Daily Work, work-item, Auto Impact, duplicate Recognition, or Consistency points.

## Privacy and safety

- Manager Board remains local-first; WorkTango CSV data is imported into the selected local Workspace and follows existing backup and restore behavior.
- No WorkTango report, Workspace, Vault, backup, business data, credentials, diagnostics, activation material, source code, private signing material, GGUF model, or projector is included in the installer or this public repository.
- This release advances the schema to v46 and preserves the accepted Workspace, Vault, Workfront, activation, updater, Local AI, backup, restore, and privacy boundaries.
