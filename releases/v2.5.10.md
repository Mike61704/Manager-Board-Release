# Manager Board v2.5.10 — Employee Plan Flexibility

Manager Board v2.5.10 makes Employee Plans reliably editable when dates, titles, and career structures change.

## What's new

- Reopen the current Employee Plan with its exact saved dates, title, role selections, narrative, and monthly roadmap.
- Change plan dates or refresh evidence without silently replacing manager-entered content.
- Prevent an older background refresh from restoring stale form values after a newer change.
- Use the updated default path from Cloud Intern directly to Cloud Engineer 1, followed by Cloud Engineer 2, Cloud Engineer 3, and Cloud Engineer Lead.
- Use Manage Career Path to add, rename, reorder, or retire roles as the team's career structure evolves.

## History and data safety

- Saving a changed plan creates a new active baseline and retains the prior plan as Superseded history.
- Historical plans keep the exact role titles they originally used, even after a role is retired from the active path.
- Career-path configuration is stored with Manager Board's existing application settings and travels with the normal SQLite backup boundary.
- Schema remains v47. Workspace, Vault, backup, activation, Local AI, employee 1:1, and manager-judgment boundaries are unchanged.
