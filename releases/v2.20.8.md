# Manager Board v2.20.8 — CPU Recommendation Context Capacity

This patch addresses incomplete recommendation outlines caused by a smaller CPU context window.

- Gives CPU the same 8,192-token input context as GPU, keeping the CPU output allowance at 1,024–2,048.
- Checks that a structured response can fit before inference and reports numeric context limits instead of silently generating partial JSON.
- Clarifies the distinction between output allowances and model context capacity.

Selected evidence is not clipped or dropped. Detailed recommendation paragraphs, indentation, HTML/PDF evidence choices and explicit manager approval remain unchanged. A larger CPU context can use more model memory. Review every generated claim.

Schema 52 and Workspace/Vault portability are unchanged. Local AI uses a separately supplied model; no model or employee data is bundled.

## Windows installer

Download **ManagerBoard-Setup-2.20.8.exe** and install over the existing version. Reload the Local AI model afterward. CPU output allowance can remain 2,048.
