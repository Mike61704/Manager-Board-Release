# Manager Board v2.13.1 — Saved Sorting and Overview Recovery

Manager Board now remembers your Project Board and task sorting with your saved workspace.

- **Remembered sorting:** choose IT Team Priority, progress, dates or names on the Project Board, and Workfront Task Number or the other existing task sorts. Your choices return when reopening the application.
- **Part of your save:** preferences follow existing backup/restore and Workspace/Vault continuity. Separate saved workspaces retain independent choices; this does not establish a different default view for every Manager Board user.
- **Overview PNG recovery:** closed-project totals include the current year, previous year and all years even when the board shows Active Projects. Team, Area and Search still scope the summary; current-view list exports retain their existing filters.
- **Safe restoration:** missing or invalid saved preferences fall back to the existing defaults, and rapid changes retain the final selection.

Existing project filters, Workfront integration, task hierarchy, current-view exports, themes, appearance, licensing, Employee Plans and Local AI are preserved. Schema 48 is unchanged. Local AI models remain optional separate files.

People using the same saved workspace share that workspace's saved preferences.
