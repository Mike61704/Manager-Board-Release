# Manager Board v2.0.65 — Unified Local AI Runtime Correction

Manager Board’s complete hardware-adaptive Local AI runtime is restored and permanently protected by the Windows build process. CPU, Vulkan GPU, and the experimental Intel NPU route are packaged together again. 🧠⚡

## What’s corrected

- Restores the complete unified CPU, Vulkan, OpenVINO, Intel NPU, and TBB runtime to the Windows installer.
- Keeps Intel NPU available as an explicit experimental Local AI route on compatible systems.
- Preserves Vulkan GPU acceleration and universal CPU fallback.
- Makes the unified runtime wheel mandatory so a reduced CPU/Vulkan-only installer cannot be produced accidentally.
- Verifies the OpenVINO backend, Intel NPU plugin/compiler/loader, and TBB components before and after application staging.

## Still true

- Local AI remains optional, private, and in process with no AI server, listener, service, or child AI process.
- GGUF models remain separate user-managed files and are never bundled in Manager Board installers.
- Review Update opens the Application Updates card, upgrades default to the newest signed release, and the Manager Board-themed installation window shows real measured progress.
- Downloaded installers must match the official repository, filename, byte count, GitHub SHA-256 digest, HTTPS path, and trusted Authenticode publisher.
- Offline device-bound activation remains valid across normal updates on the same Windows profile.
- Schema v41, Workfront safety, backup/restore, session privacy, and Workspace/Vault protections are unchanged.
- No source code, private signing material, organization data, user data, or GGUF model is included.
