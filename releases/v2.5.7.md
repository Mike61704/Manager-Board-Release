# Manager Board v2.5.7 — Manager Work Attachment Reliability

Manager Board v2.5.7 keeps Manager Center work-item attachments reliable when screenshots or selected files arrive with names already used on the same item.

## What's new

- Pasted Manager Work screenshots receive a precise local date-and-time filename instead of sharing one date-only name.
- If a filename still conflicts, Manager Board preserves the new attachment with a timestamped name and sequence instead of rejecting the entire work-item save.
- Selecting multiple files with repeated names preserves every supported file and shows the unique name that will be stored.
- The Python attachment service provides the final collision safeguard, including for older clients or imported requests.

## Existing behavior preserved

- Explicit attachment replacement still replaces the selected existing attachment.
- Every attachment retains its own durable Vault path, attachment ID, SHA-256 validation, Files index entry, and backup relationship.
- The 25 MB per-file and 100 MB per-Manager-Work-item limits are unchanged.
- Manager Center layout, work-item data, Local AI, WorkTango and Ivanti imports, scoring, themes, accessibility, and schema v46 are unchanged.

## Validation and safety

- Focused and expanded regression cover repeated case-insensitive names, timestamp and sequence fallback, separate file bytes, explicit replacement, Vault durability, Files indexing, schema, and Manager Center UI contracts.
- The official release process requires complete regression, real-model quality checks, packaged-runtime and public-payload audits, Microsoft signing, timestamping, stable-publication verification, and installed smoke.
- No Workspace, Vault, backup, business data, credentials, diagnostics, activation material, source code, private signing material, GGUF model, or projector is included in the installer or this public repository.
