# Manager Board v2.7.3 — Project Exports and Workfront Assignments

This maintenance release fixes project exports and saved task assignments for Workfront publishing.

- Export Current View respects the open project and its visible task filters, grouping and sort order. XLSX, CSV, JSON and HTML exports use that project view.
- Assigning managed Workfront users to previously unassigned tasks now appears in Modified Changes and Review & Publish.
- A previous Discard reconciliation no longer hides later assignment changes.
- Already-saved assignment edits are detected without repeating the bulk edit.

Editor drafts and final Workfront publish confirmation are preserved. The installer upgrades the application while retaining activation and Workspace data. Schema 48 is unchanged, and optional Local AI models remain separate.
