# Manager Board v2.6.1 — Drafts Settings and Help

Manager Board v2.6.1 makes unfinished drafts easier to find and explains recovery through contextual Help.

## Improvements

- Find Unfinished drafts in the Settings list, immediately above Backup, Restore & Vault.
- Read clearly named Drafts recovery guidance from Settings and General Settings Help.
- Open recovery Help directly with Help or F1 in the draft window, and return to Settings Help.
- Find guidance on recovered content, staged attachments, explicit saving, and safe closing from the relevant editor Help topics.

## Preserved behavior

Schema stays at 48 with no new migration from v2.6.0. Draft capture timing and explicit Save behavior are unchanged. Existing performance improvements, Remote Desktop graphics compatibility, Workspace/Vault separation, and privacy boundaries remain intact. Optional Local AI models remain separate and are never bundled.
