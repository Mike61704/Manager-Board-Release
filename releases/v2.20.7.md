# Manager Board v2.20.7 — Recommendation Outline Reliability

This patch improves the first drafting step for Employee Plans recommendations.

- Requires each outline topic to reference selected work or manager observations, while keeping overall ratings available for decision and review context.
- Keeps the outline brief before developing the separate evidence paragraphs.
- Gives the automatic retry the specific validation reason and explains an outline failure without exposing the model response.
- Explains when selected records contain no supporting observations or work evidence. The editable source draft remains available.

The existing preview remains available if generation fails or is cancelled. Detailed recommendation paragraphs, indentation, HTML/PDF exports with or without evidence, and explicit manager save/approval remain unchanged. Source-reference checks do not verify every generated claim; managers must review the draft.

This patch addresses outline failure paths. It does not establish the cause of any particular CPU-versus-GPU difference, and does not require a GPU. Local AI remains optional and uses a separately supplied compatible model; no model or employee data is bundled.

Schema 52 is unchanged. Existing plans, saved reviews, recommendation snapshots and Workspace/Vault portability are preserved.

## Windows installer

Download **ManagerBoard-Setup-2.20.7.exe** and install it over the existing installation. User data remains separate from replaceable application files.
