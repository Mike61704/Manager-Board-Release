# Manager Board v2.6.3 — Overview History Totals

This maintenance update keeps current-year and imported history totals together in Export Overview PNG.

## Fixes

- Normal Workfront synchronization retains imported prior-year project totals.
- Importing a history year preserves current task and project totals in the Overview.
- Repeated history imports replace that year's totals without adding duplicate projects.
- Reopened projects and changed completion years are reconciled using recorded project identifiers.
- Existing trusted import evidence is used where available without changing saved project records.

The Overview layout is unchanged. Schema remains 48 with no new migration. Workspace/Vault separation and privacy boundaries remain intact. Optional Local AI models remain separate and are not bundled.

## Validation

The focused reporting and Workfront regression passed 113 tests, and the product owner accepted desktop source smoke testing. The supported release pipeline requires complete regression, real-model quality, runtime, and trusted signing checks before publishing the installer.
