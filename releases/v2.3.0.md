# Manager Board v2.3.0 — Public Support and Recovery Reliability

Manager Board now provides clear public support and feedback entry points and
makes Windows restore-point cleanup more reliable.

## What’s improved

- Adds Report a Problem, Suggest a Feature, Get Help, and View Known Issues to
  Help.
- Adds Report a Problem and Suggest a Feature to Settings > About / Version.
- Opens problem, feature, and help actions directly in their matching public
  issue forms, while known issues opens the public issue list.
- Clearly warns that public reports must not contain employee data, credentials,
  activation files, backups, diagnostics, or organization-sensitive
  information.
- Allows restore-point delete, retention cleanup, orphan cleanup, and delete-all
  to remove recovery packages containing read-only Windows files or folders.
- Corrects corrupted separator text on restore-point cards.

## Safety and continuity

- Support actions open only approved HTTPS destinations in this public release
  repository and do not transmit Manager Board data automatically.
- No GitHub sign-in, GitHub API integration, business-data handling, or database
  migration is added.
- Schema remains v45.
- Existing Workspace, Vault, Workfront, activation, backup, restore, Local AI,
  updater, and privacy boundaries remain intact.
- No GGUF model, source code, business data, credentials, diagnostics, or
  private signing material is included in this release repository.
