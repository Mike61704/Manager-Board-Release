# Manager Board v2.0.63 — Visible Upgrade Progress

Manager Board updates no longer disappear into a quiet gap after the app closes. This release keeps a branded installation window visible while the verified upgrade is installed, so you can see that progress is continuing. 🚀

## What’s new

- Approved updates now open a Manager Board-themed dark installation window after the protected application session closes.
- The window shows Inno Setup’s real file-installation progress instead of a time-based animation.
- Manager Board’s logo and update-specific wording make it clear that a verified application update is underway.
- The progress window remains visible until installation finishes and Manager Board relaunches.
- The same visual treatment is used for normal interactive installation and in-app upgrades.

## Still true

- Downloaded installers must match the official repository, versioned filename, byte count, GitHub SHA-256 digest, HTTPS release path, and trusted Authenticode publisher before installation.
- Manager Board releases its protected Workspace and Vault session before starting an update.
- Offline device-bound activation remains valid across normal updates on the same Windows profile.
- Automatic installation remains off until the user chooses a schedule.
- The core workspace remains local-first.
- Schema v41, Workfront safety, Local AI isolation, backup/restore, session privacy, and Workspace/Vault protections are unchanged.
- No source code, private signing material, organization data, user data, or GGUF model is included.
