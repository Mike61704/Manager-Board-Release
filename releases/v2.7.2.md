# Manager Board v2.7.2 — Workfront Intake Publishing

This patch repairs the path from an intake workbook to reviewed Workfront publishing.

## Fixed

- New imported projects and tasks appear in Modified Changes, including tasks left after a partial publish.
- Intake ignores predecessor dependencies while preserving parent/child grouping and planned dates. Re-import clears predecessor values on matching imported tasks.
- The imported project opens after intake instead of automatically opening XLSX export.
- Send Project to Workfront offers a primary Review & Publish action and carries only checked tasks into the final review.
- The default selection count matches checked tasks. The XLSX fallback preview waits for the task selection to finish loading.

Workfront writes still require review and final publish confirmation. XLSX export remains available as a fallback. Other editor drafts, schema 48, user data and separate optional Local AI models are preserved.
