# Manager Board v2.20.3 — Monthly AI Output Reliability

This patch improves **Draft from Selected Evidence** for monthly Employee Plan Manager Notes.

- Constrains monthly response formatting during local generation, improving reliability with quoted work-item text and preventing malformed JSON delimiter errors.
- Keeps long-month summaries compact with representative references while retaining every selected input record for the model.
- Preserves existing notes when a request fails and shows a useful message if a response remains incomplete after the bounded repair.
- Keeps the normal preview, edit and explicit insertion workflow. Review generated wording and factual claims before accepting it.

Existing reviews, ratings, completed 1:1 records, other Local AI workflows and Workspace/Vault portability are preserved. Schema 51 is unchanged. Local AI remains optional, local and dependent on a separately supplied model; no model is bundled.

## Windows installer

Download **ManagerBoard-Setup-2.20.3.exe** and install it over the existing Manager Board installation. User data stays separate from replaceable application files.
