# Manager Board v2.5.6 — Image Analysis Recovery

Manager Board v2.5.6 makes local screenshot and image analysis recover safely when the accelerated vision projector cannot complete a request.

## What's new

- A failed GPU or NPU vision-projector evaluation retries the complete prepared image prompt once on CPU.
- Only the image projector changes routes during recovery; normal text-model inference remains on the selected backend.
- A successful recovery continues the same Chat request without requiring the image to be attached again.
- If recovery also fails, Manager Board reports the projector route, prepared image dimensions, prompt positions, image-token count, and bounded native failure detail when available.
- Local AI status now includes the active projector route for support diagnostics.

## Existing behavior preserved

- Images remain session-only and local to the Manager Board process.
- Image bytes are not saved to SQLite, Workspace, Vault, backups, exports, or diagnostics.
- No GGUF model or projector is bundled.
- Text-only Local AI remains available when no compatible projector is configured.
- Navigation paging, recognition scoring, WorkTango and Ivanti imports, reporting, themes, accessibility, and schema v46 remain unchanged.

## Validation and safety

- Focused Local AI regression covered accelerated failure, CPU retry, route reporting, and terminal diagnostics.
- The configured Qwen3.5 model and matching projector passed normal screenshot analysis on Vulkan.
- A controlled code 1 projector failure recovered on CPU and returned an image analysis while the text model remained on GPU.
- The official release process requires complete regression, real-model quality checks, packaged-runtime and public-payload audits, Microsoft signing, timestamping, stable-publication verification, and an independent public download check.
- No Workspace, Vault, backup, business data, credentials, diagnostics, activation material, source code, private signing material, GGUF model, or projector is included in the installer or this public repository.
