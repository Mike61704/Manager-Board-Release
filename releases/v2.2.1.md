# Manager Board v2.2.1 — Workfront Scope Compatibility

Manager Board now supports Workfront teams that do not use a request custom
form. A manager can leave the request-form setting blank and still synchronize
the projects and tasks authorized by their verified Home Team and project
authority Group.

## What’s new

- Makes **Request custom form scope** optional in Workfront Connection Settings.
- Keeps project and task synchronization available through the verified
  operational Home Team and project-authority Group when no form is configured.
- Retains exact custom-form validation and form-based project discovery whenever
  a form name is supplied.
- Clears stale request-form metadata after a trusted form-free synchronization.
- Allows reviewed new-project publishing without a category when the manager has
  no configured request form.
- Clarifies the setup guidance and saved-settings status for managers using the
  form-free configuration.

## Safety and continuity

- Workfront Group and Team authority checks remain required and unchanged.
- Existing Workfront session privacy, trusted-snapshot, authoritative-pruning,
  and reviewed-publishing boundaries remain intact.
- Schema remains v44, so existing Manager Board workspaces continue through the
  normal upgrade path.
- The complete CPU, Vulkan, OpenVINO Intel NPU, and TBB runtime remains included.
- No source code, private signing material, organization data, user data, or
  GGUF model is included.
