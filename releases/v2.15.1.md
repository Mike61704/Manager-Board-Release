# Manager Board v2.15.1 — Workfront Conversion Recovery

- **Reliable conversion confirmation:** handles conversion action results and checks the original request's project link when Workfront completes a conversion without returning a recognized project ID.
- **Task publishing after Sync:** reconciles an unfinished conversion record when synchronization already linked its existing project. The original request, connection, template and group are verified before selected tasks publish.
- **Clear recovery:** Recheck recognizes an already converted request and offers Finish Project Setup. Uncertain retries retain their saved identity and do not send another conversion. Failed publish confirmations require a fresh review.
- **Cleaner review dialogs:** separates the description and confirmation field, groups conversion actions, and adds spacing around publish action rows and footer buttons in dark, light and narrow views.

After updating, connect and Sync Workfront. For a previously converted request, use Recheck to verify the existing project; then review and publish any remaining selected tasks. Approvals, permissions and configured scope remain enforced. Connected-system conversion and task publication should be verified in your Workfront environment.

Existing projects, task hierarchy, saved sorting and column widths, exports, backups, themes, licenses and Workspace/Vault continuity are preserved. Schema 48 is unchanged. Local AI models remain optional separate files.
