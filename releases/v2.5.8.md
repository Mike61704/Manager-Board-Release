# Manager Board v2.5.8 — Workfront Performance and History

Manager Board v2.5.8 keeps large Workfront Boards responsive and makes historical imports intentional while preserving existing data.

## What's new

- Default sync includes all active team projects, regardless of start year, plus closed or completed projects whose actual completion date falls in the current calendar year.
- All Project Tasks also shows active tasks assigned to your people on projects outside the team's project list, alongside current team-project tasks.
- Import History retrieves older closed or completed projects directly from Workfront by selected completion year. Historical imports are additive and stay separate from normal active/current views and calculations.
- History imports and large syncs show a preview before importing.
- Bounded task pages, lazy task groups, faster database queries, and background change counts keep large Boards responsive.
- Workfront permission and publish errors preserve local edits, release busy controls, and provide readable technical details for troubleshooting.

## Upgrade and data safety

- A safe schema v47 migration classifies previously imported Workfront history without requiring a Board reset or deleting unrelated data.
- People, Notes, Daily Work, Leaderboard, settings, local edits, and unrelated Board records remain intact.
- Application upgrades keep Workspace, Vault, backups, attachments, and activation outside the replaceable application files.
- Local AI remains optional and local. No model is bundled.

## Validation

Regression coverage includes recovery of a simulated existing Board with approximately 166 projects and 11,453 tasks, a 12,000-task scenario, history separation, outside-project assignments, restore/restart, and publish-error recovery. The complete release regression passed 2,337 tests; the official build passed 109 package checks and all 20 real-model quality cases. Required signature, runtime, and payload audits passed. Product-owner source and installed-build smoke passed, along with automated installed desktop checks.
