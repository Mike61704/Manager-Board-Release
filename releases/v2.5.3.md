# Manager Board v2.5.3 — Compact Manager Center

Manager Board v2.5.3 makes Manager Center easier to scan while preserving the WorkTango reporting introduced in v2.5.2.

## What's new

- Fit all eight Manager Center summary metrics into one shorter row on wide desktop displays.
- Use compact metric labels while preserving full accessible names and explanatory tooltips.
- Retain four-column and two-column responsive layouts on narrower windows.
- Keep the manager's WorkTango award count and point total visible while collapsing the individual recognition cards by default.
- Expand or collapse manager WorkTango award details with the keyboard-accessible **Show awards** / **Hide awards** control.
- Preserve the selected WorkTango disclosure state during Manager Center refreshes in the current view.

## WorkTango behavior preserved

- Employee Leaderboard scoring continues to count a positive award when the recipient matches an active Manager Board person and the sender is either the configured manager or someone outside the active team.
- Recognition exchanged between active team members does not score.
- WorkTango Admin/system activity, zero-point activity, and unmatched employee recipients do not score.
- Positive awards received by the configured manager remain matched through Manager Profile email and reported only in Manager Center.
- WorkTango recognition does not create manual Daily Work, work-item, Auto Impact, duplicate Recognition, or Consistency points.

## Validation and safety

- The exact release source passed 2,287 tests with one skip and four established warnings.
- A signed private installer passed installed product-owner smoke before public publication.
- Manager Board remains local-first; imported WorkTango data stays in the selected local Workspace and follows existing backup and restore behavior.
- No WorkTango report, Workspace, Vault, backup, business data, credentials, diagnostics, activation material, source code, private signing material, GGUF model, or projector is included in the installer or this public repository.
- This release retains schema v46 and preserves the accepted Workspace, Vault, Workfront, activation, updater, Local AI, backup, restore, scoring, reporting, and privacy boundaries.
