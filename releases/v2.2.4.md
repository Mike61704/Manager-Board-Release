# Manager Board v2.2.4 — Local AI Code Integrity Hotfix

Manager Board now signs and verifies its native Local AI runtime components so
Windows code-integrity protection can load the optional on-device AI runtime
without rejecting unsigned llama.cpp or ggml libraries.

## What’s fixed

- Signs the Manager Board-owned native llama.cpp and ggml runtime libraries
  included with the Windows application.
- Verifies every packaged native Local AI binary before the installer is built.
- Signs and verifies the installer’s embedded setup and uninstaller components,
  as well as the completed installer.
- Prevents repeated native Windows loader dialogs if an optional Local AI
  component is still unavailable, while Manager Board continues working
  normally.

## Safety and continuity

- Local AI remains optional, private, and on-device.
- The compatible GGUF model remains a separate user-managed file and is never
  bundled in Manager Board or this release repository.
- Existing Workspace, Vault, Workfront, activation, backup, restore, Help,
  Welcome Guide, Diagnostics, updater, and privacy boundaries remain intact.
- Schema remains v45.
