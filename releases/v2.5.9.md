# Manager Board v2.5.9 — AI-Assisted 1:1 Preparation

Manager Board v2.5.9 adds private, evidence-grounded drafting assistance to Employee 1:1 preparation while keeping every suggestion and rating under the manager's control.

## What's new

- Generate reviewable Local AI suggestions for Manager Preparation, Topics to Discuss, Wins & Recognition, Current Priorities, Discussion, Blockers / Support Needed, and Development & Growth.
- Receive concise example comments for each Check-in category without allowing AI to select, recommend, or overwrite a rating.
- Use the employee linked to the saved 1:1 and an inclusive evidence window from the meeting date through fourteen days prior.
- Review, edit, copy, and insert suggestions individually, or use Include All Suggestions to add every remaining supported suggestion.
- Copy a bounded preparation prompt for Copilot without sending any information automatically.

## Privacy and data safety

- Manager-private evidence is available only to manager-only preparation fields and is excluded from shared narratives and Check-in comments.
- Every displayed Manager Board evidence reference is validated against the bounded records supplied to that generation pass.
- Existing manager-entered content is preserved. Inserted suggestions are appended and remain unsaved until the normal Save Preparation action is used.
- A malformed or unsupported individual AI field is safely omitted without discarding other valid suggestions.
- Local AI remains optional and runs inside Manager Board. No AI model is bundled.
- Schema remains v47. Workspace, Vault, backup, activation, and existing 1:1 data boundaries are unchanged.

## Validation

Product-owner source smoke passed with new, existing, and older 1:1 records in an isolated Test Workspace. The exact release-aligned source passed 2,349 tests with four established warnings. The official build additionally enforces package, real-model quality, dependency, runtime, public-payload, signing, timestamp, and publication verification gates.
