# Manager Board v2.2.2 — Manager 1:1 and Local AI Polish

Manager Board now gives managers direct control over which preparation sections
appear in a manager-facing 1:1 preview or export, and restores clearly distinct,
useful Local AI rewrite styles.

## What’s new

- Adds default-on **Include in preview/export** controls to all nine Manager 1:1
  preparation and commitment sections.
- Keeps excluded section text saved privately while removing the section entirely
  from preview and theme-aware HTML export.
- Makes Professional, Manager Style, Casual, Concise, and Expand & Structure
  rewrites visibly distinct while retaining the source meaning.
- Protects discussion-only, future-action, future-time-off, and named-person
  language from unsupported factual changes.
- Retries once when a transformative rewrite returns the source unchanged, while
  preserving minimal-change proofread behavior.

## Safety and continuity

- Local AI continues to run in process with no AI server, listener, service, or
  child AI process.
- GGUF models remain separate, optional, and user managed; no model is bundled.
- Existing Workspace, Vault, Workfront, activation, backup, restore, Help,
  Welcome Guide, Diagnostics, and employee/manager 1:1 boundaries remain intact.
- Schema advances to v45 through the normal validated workspace upgrade path.
- The complete CPU, Vulkan, OpenVINO Intel NPU, and TBB runtime remains included.
- No source code, private signing material, organization data, or user data is
  included.
