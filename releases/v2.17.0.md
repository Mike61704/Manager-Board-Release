# Manager Board v2.17.0 — Onboarding Sections and Workfront Publishing

- **Sections and sub-checks:** group onboarding steps under named sections and tasks. Parent status follows its sub-checks automatically, and only individual checks count toward completion.
- **Reusable starters:** a general employee checklist covers arrival, building access, equipment, orientation and first-month follow-up. An optional cloud services starter adds accounts, team tools, security, training and access validation. Customize a copy for your team in Settings > People & Aliases > Onboarding Templates.
- **Readable exports:** HTML/PDF retain sections, task groups, completion markers, dates, owners, notes and progress totals. XLSX/CSV identify task summaries and sub-check rows for reliable reuse.
- **Portfolio HTML repair:** All Teams and selected Workfront Team filters now export through the Projects toolbar correctly.
- **Workfront publishing repair:** undated tasks use Workfront scheduling rather than an invented start date that can precede the converted project's start time. Chosen project starts and explicit task dates remain preserved. An interrupted publish retains its confirmed project link and remaining local changes.

Existing flat onboarding checklists and independently saved employee progress are preserved. New hierarchical onboarding documents require this version or newer; older versions refuse those documents rather than flattening their sub-checks. Template changes affect future copies. Normal backup, restore, Vault, theme, license, sorting and column-width behavior remains intact. Schema 48 is unchanged; Local AI models remain optional separate files.

After updating, open an employee's Onboarding strip or manage templates from Settings > People & Aliases. For a new Workfront intake, set the project Planned Start Date when known and leave task dates blank when Workfront should schedule them. A previously deleted project must be imported again. Review and confirm selected changes before publishing.
