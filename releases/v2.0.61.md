# Manager Board v2.0.61 — Secure Installer Updates

Manager Board can now keep an eye on this official release channel and help you move to a newer signed installer without turning update day into a scavenger hunt. 🚀

## What’s new

- A new full-width **Application Updates** card lives directly below the Offline License card in About.
- Manager Board checks the public release channel for the installed release and newer stable versions.
- Release notes and explicit upgrade choices are available in the application.
- A non-blocking toast announces a newer version, and General reflects update availability.
- Updates can remain manual or follow a user-selected scheduled time, protected shutdown, or next-startup policy.
- Downloads show real byte-based progress.
- Every staged installer must match the exact repository, versioned filename, byte count, GitHub SHA-256 asset digest, HTTPS release path, and trusted Manager Board Authenticode publisher.
- Shutdown installation waits until Manager Board releases its protected Workspace/Vault session. Next-startup installation runs before business data opens.

## Still true

- Offline device-bound activation remains valid across normal updates on the same Windows profile.
- Automatic installation is off until the user chooses a schedule.
- The core workspace remains local-first.
- Schema v41, Workfront safety, Local AI isolation, backup/restore, session privacy, and Workspace/Vault protections are unchanged.
- No source code, private signing material, organization data, user data, or GGUF model is included.
