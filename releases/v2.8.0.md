# Manager Board v2.8.0 — Existing Workfront Project Revisions

Revise an existing Workfront project's tasks through a workbook, with a clear preview before publishing.

- **Revise Project** exports existing task identities with explicit **Keep**, **Update**, **Add** and **Delete** actions.
- Import previews before and after values and stages changes in **Modified Changes**. **Review & Publish to Workfront** sends only the selected, confirmed changes.
- Missing rows and blank cells leave existing data unchanged. Use **[CLEAR]** to clear supported fields explicitly.
- Task deletion checks identity, project, children, dependencies and history. Resolve linked children and dependencies before deleting a task. Comments, documents and time entries are not transferred into another task.
- Saved task identities and publish receipts prevent blind duplicate retries after uncertain responses.

Use the new revision export for this workflow; ordinary report exports and intake workbooks retain their existing behavior. Parent IDs are reference-only, and newly added revision tasks start at project root.

Schema 48 is unchanged. The installer retains activation and Workspace data. Optional Local AI models remain separate.
