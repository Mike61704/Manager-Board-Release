# Manager Board v2.20.1 — Bulk Edit and Recurring Work Fixes

- **Bulk edits keep their safety snapshot:** long Windows attachment paths no longer prevent the automatic restore point solely because staging adds extra folder depth. The complete backup and file validation remain required before tasks change.
- **Open the document from either work card:** recurring Manager Work reminders now show the saved work instructions. Web links in both the original and reminder cards open in the Windows default browser, keeping Manager Board open and preserving the complete document-link query.
- **Keep text inside its card:** long URLs and unbroken text wrap within Manager Center cards in dark, light, narrow and two-column layouts. Existing named links, rich formatting and privacy blur remain supported.

Schema 51 is unchanged. Existing attachment bytes, saved narratives, completed occurrences, completed 1:1 history, Follow-ups and employee plans remain preserved. Each new occurrence retains its own outcome; a completed outcome is not carried into the next date. A genuinely unavailable attachment still stops bulk editing before tasks change.

After updating, open Manager Center > All or Manager items due and use the link in the work instructions. Project bulk editing continues to create its automatic safety restore point. Optional Local AI models remain separate files.
