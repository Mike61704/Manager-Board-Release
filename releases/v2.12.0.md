# Manager Board v2.12.0 — Workfront Projects Reliability and Filters

This release improves Workfront project imports, pending-change recovery, team filtering and priority rankings.

- **Reliable assignee matching:** imported tasks use saved Workfront user IDs and exact email/UPN matches before display names. Unresolved assignees are grouped once per person, and import review distinguishes staged tasks from publishable changes.
- **Unpublished task recovery:** discard local-only imported tasks atomically, including their pending changes and draft records, without modifying Workfront. Published task history and uncertain remote creates remain protected.
- **Workfront Team filters:** select one or more teams from the Projects toolbar. Membership uses actual task and assignment Team IDs, supports projects spanning multiple teams and combines with existing filters. Current-view exports honor the same selection.
- **Team priority rankings:** sync the custom team priority field, display its numeric ranking and sort ascending or descending. Standard Workfront Project Priority remains separate; sync again to retrieve previously missing custom rankings.

Existing Projects, appearance, export themes, Employee Plans, Local AI, licensing and storage behavior are retained. Schema 48 is unchanged. Workspace, Vault and recovery data remain separate from replaceable application binaries. No Local AI model, private signing key or customer data is bundled.

The public build passes complete regression and the supported dependency, model, runtime, payload and compiler-integrated signing gates before publication. Testing uses isolated synthetic Workspaces; separate human installed/live acceptance is not claimed.
