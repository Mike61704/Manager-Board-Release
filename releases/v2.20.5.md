# Manager Board v2.20.5 — Recommendation Reliability and Historical Plan Cleanup

This patch fixes repeated recommendation generation failures and adds a deliberate way to remove historical test plans.

- Generates recommendation sections with selected evidence IDs separately, then adds the recorded role/review header and source references consistently in the application.
- Automatically retries invalid formatting once and preserves the existing preview if generation still fails or is canceled. Generated text remains editable and unapproved until explicitly saved/approved by a manager.
- Keeps leadership previews clean and retains references in HTML/PDF exports that include evidence.
- Adds Delete Historical Plan for ended or superseded plans, with exact title/dates and review/draft counts shown before confirmation.
- Permanently removes only the confirmed plan, saved reviews, linked legacy tracking and associated unsaved review drafts. Current plans, independent Path to Promotion records and saved recommendation snapshots remain intact.

Permanent deletion cannot be undone in the app. Existing saved recommendation snapshots and backups retain their original records; snapshots using deleted sources remain viewable/exportable but cannot be refreshed from those deleted records. Review the confirmation carefully and create a backup when appropriate.

Schema 52 is unchanged. Existing ratings, other plans, history and Workspace/Vault portability are preserved. Local AI remains optional and uses a separately supplied model; no model or employee data is bundled. Review generated claims before approval; a recommendation is not an HR promotion approval.
