# Manager Board v2.13.2 — Workfront Closed Project Counts

The Workfront Overview now includes completed projects discovered through assignments to employees in your configured connection scope.

- **Complete project counts:** current-year totals include completed assignment-linked projects alongside the main team portfolio.
- **Team-filtered summaries:** stored Workfront project and assignee IDs keep those completions available to Overview Team, Area and Search filters, including projects without current task rows.
- **Preserved active work:** active assignments on outside projects remain available, while normal portfolio views and current-view list exports retain their established scope.
- **Startup repair:** an existing Workspace awaiting Vault setup can show its startup message correctly.

After updating, run **Sync Workfront**. To refresh prior-year totals, use **Import History** for the required year before exporting the Overview. Counts follow Workfront completion dates and the verified connection scope; expected numbers are never hard-coded.

Saved sorting, task hierarchy, publishing, rollback, themes, licensing, Employee Plans, Local AI and Workspace/Vault continuity are preserved. Schema 48 is unchanged. Local AI models remain optional separate files.
