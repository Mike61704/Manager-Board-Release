# Manager Board v2.11.0 — Employee Plans and Consolidated Workflows

This release brings the remaining Employee Plans, Local AI reporting and Workfront improvements together in one signed public update.

- **Employee Plan Manager Notes:** use **AI Assist → Draft from Selected Evidence** to create a monthly summary from the employee's checked records, even when notes are empty. Review, edit and accept the example, then explicitly save the review. Existing rewrite modes remain available. Assessments remain the manager's decision.
- **Local AI business visuals:** preview High Impact by employee, Project Task Status and Project Task Completion Trend. The model proposes a validated layout while Manager Board supplies the authoritative figures and renders the graph safely.
- **Workfront task ordering:** hierarchical Start Date sorting is the default. Parent/child relationships and selectable sort modes remain available; missing or invalid dates sort last without changing stored data.
- **Workfront batch deletion review:** harmless sibling modification metadata, renumbering and collection order no longer cause repeat review failures. Per-task content, history and assignment checks remain required. Publication reviews do not create recovery drafts, and partial publication clearly reports applied and remaining work.

Complete wins and recognition, background AI startup with its ready notification, private 1:1 preparation, Adobe Native and legacy sign-in, existing licenses and storage behavior are retained. Schema 48 is unchanged. Workspace, Vault and recovery data remain separate from replaceable application binaries. No Local AI model or private signing key is bundled.

The public build passes complete regression and the supported dependency, model, runtime, payload and compiler-integrated signing gates before publication. Testing uses isolated synthetic Workspaces; separate human installed/live acceptance is not claimed.
