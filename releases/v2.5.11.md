# Manager Board v2.5.11 — Review Evidence Selection

Manager Board v2.5.11 gives managers broader, explicit control over the evidence included in Employee Plan reviews and improves the readability and routing of related records.

## What's new

- Open a searchable Choose Evidence window for each Manager Review month.
- Select from every completed project task and counted Daily Work item in the month, together with positive manager evidence.
- Start with high-value project tasks, high-impact work, and positive manager evidence recommended, then add or remove any available item.
- Keep the main review compact by showing only the evidence the manager selected.
- Carry only selected evidence into saved review snapshots, Local AI or Copilot prompts, previews, and HTML/PDF reports.

## Readability and Chat routing

- Convert stored rich-text evidence into readable review text instead of exposing HTML markup, including evidence in older saved review snapshots.
- Route employee questions phrased as “1 on 1” to verified Manager Board employee and 1:1 records when Chat is in Auto mode.
- Keep Local AI generation private and on-device, with coherent sentence and paragraph output supported by the existing separately managed model workflow.

## History and data safety

- Preserve evidence selections by stable identity across saves and evidence refreshes, with backward-compatible handling for older reviews.
- Keep ratings, employment decisions, progression decisions, and final evidence inclusion under manager control.
- Continue excluding manager-private 1:1 content from shared review evidence.
- Schema remains v47. Workspace, Vault, backup, restore, activation, Local AI, and manager-judgment boundaries are unchanged.
