# Manager Board v2.5.4 — Recognition Tier Values

Manager Board v2.5.4 increases the two highest manual recognition tiers and keeps every scoring explanation aligned with the calculated Leaderboard result.

## What's new

- High Impact / Major Win recognition now contributes 50 points instead of 35.
- Certification / Credential recognition now contributes 100 points instead of 50.
- Existing and future recognition recorded through Notes or Daily Work uses the updated values.
- Daily Work and Notes selectors show the new point amounts.
- Leaderboard guidance, score audits, and HTML exports show the same tier values used by scoring.

## WorkTango behavior preserved

- Eligible WorkTango recognition continues to use its imported point value.
- Employee Leaderboard eligibility, manager reporting, sender attribution, deduplication, and import behavior are unchanged.
- WorkTango recognition still does not create manual Daily Work, work-item, Auto Impact, duplicate Recognition, or Consistency points.

## Validation and safety

- Product-owner source acceptance passed before merge.
- The accepted scoring change passed 146 focused scoring, Daily Work, Notes, Leaderboard, bridge, parity, release-metadata, and workflow tests before release alignment.
- Manager Board remains local-first; recognition data stays in the selected local Workspace and follows existing backup and restore behavior.
- No Workspace, Vault, backup, business data, credentials, diagnostics, activation material, source code, private signing material, GGUF model, or projector is included in the installer or this public repository.
- This release retains schema v46 and preserves the accepted Workspace, Vault, Workfront, activation, updater, Local AI, backup, restore, reporting, and privacy boundaries.
