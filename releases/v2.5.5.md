# Manager Board v2.5.5 — Navigation and Paging Performance

Manager Board v2.5.5 keeps long, record-heavy views responsive and gives the active module more room when you want it.

## What's new

- Small persistent controls collapse and expand both navigation rails throughout Manager Board.
- Navigation state carries across modules, and the controls remain keyboard accessible.
- Delayed repaint work was removed so a collapsed menu restores promptly after long scrolling sessions.
- Daily Work, Manager Center, Follow-ups, Notes, and Reflections now show 10 records initially and up to 20 records on later pages.
- Previous and Next replace the current page instead of retaining every earlier card, reducing browser memory and redraw work.
- Filters, searches, and focused-record links reset safely to the first matching page.

## Existing behavior preserved

- Projects retains its existing database-backed task pagination.
- Files retains its bounded Recent view and filtered explorer.
- People, Calendar, and Leaderboard remain naturally bounded.
- Recognition scoring, WorkTango imports and reporting, Ivanti imports, exports, themes, and accessibility behavior are unchanged.

## Validation and safety

- Accepted feature source was merged and remote verified before release alignment.
- Focused Qt WebEngine tests exercised 55 records in each newly paged feed and confirmed 10-card initial pages and 20-card later pages without card accumulation.
- Manager Board remains local-first and schema remains v46.
- No Workspace, Vault, backup, business data, credentials, diagnostics, activation material, source code, private signing material, GGUF model, or projector is included in the installer or this public repository.
- This release preserves the accepted Workspace, Vault, Workfront, activation, updater, Local AI, backup, restore, reporting, and privacy boundaries.
