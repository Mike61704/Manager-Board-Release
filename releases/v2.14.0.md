# Manager Board v2.14.0 — Project Insights and Workfront Request Backlog

This release improves project analysis, makes project and task tables easier to read, and adds a Workfront request workflow with separate backlog visibility.

- **More useful project answers:** optional Local AI can combine project descriptions, completed and remaining task narratives, and related Daily Work to explain what the work means. Recorded status and inferred readiness remain distinct.
- **Saved column widths:** resize columns in Project Board, Project Tasks and All Project Tasks. Widths belong to the saved Workspace, survive restarts and backup/restore, and can be reset separately for each view.
- **Request-based project creation:** configure a Workfront request queue/topic and project template in Connections. New intake collects required request-form values, submits a request and converts it using the template, leaving the Workfront project manager unassigned. Existing-project imports retain their established workflow.
- **Request Backlog:** open Projects → Request Backlog to search and sort cached open requests, with unassigned and all-open views. Submit new intake as Request Backlog only, then convert the same request later while keeping tasks staged until publication.
- **Connection guidance:** updated Adobe Native App wording, more precise session-expiry handling and provider-reported sign-in timing when available.
- **Desktop compatibility:** improved Remote Desktop browser graphics defaults and refreshed development-checkpoint exports.

For request creation and backlog visibility, configure the intended template and request form's Share path in Connections, then run Sync Workfront. Required form choices come from Workfront metadata. Template project sharing, queue routing, approvals and report visibility follow your organization's Workfront configuration; this release does not broaden access or bypass approvals.

Existing-project imports, reviewed publishing and rollback, saved sorting, task hierarchy, exports, themes, licensing and Workspace/Vault continuity are preserved. Schema 48 is unchanged. Local AI models remain optional separate files.
