# Manager Board v2.10.1 — Consolidated Production Readiness

This consolidated update improves employee recognition, Adobe Native sign-in feedback, license security visibility, and employee intake updates.

- **Employee History > Wins / Recognition** now includes recognized Daily Work, including certification badges, item recognition and saved shared 1:1 wins in the displayed date range. Draft meeting wins are labeled draft.
- **1:1 AI preparation** receives day-level recognition, recognized work items and eligible WorkTango awards. Recognized evidence is retained when ordinary activity fills the context window. Suggestions remain reviewable before insertion; certification is not attributed to unrelated work items.
- **Adobe Native sign-in** opens a separate local browser completion page after authorization reaches Manager Board. Safe error details are available when consent fails. Connection and sync status remain in Manager Board. Existing PKCE/state/protocol protection and Legacy sign-in are preserved.
- **Settings > Security** shows trusted license key IDs, SHA-256 fingerprints, the installed license key and next-build key designation. Installed trust management is read-only. Existing licenses continue to verify; public-key rotation is owner/developer source tooling for subsequent signed builds.
- **Workfront Intake** updates renamed tasks by stable Task # when appropriate. Conflicting identities identify the number and titles instead of exposing a database exception. Source-authoritative tasks and deleted records remain protected. Unresolved assignee names remain separate warnings.

Schema 48 is unchanged. Activation, Workspace, Vault and recovery data remain separate from application binaries. Optional Local AI models are not bundled. This is the first public release of the consolidated 2.10 workstream; the earlier private 2.10.0 candidate was not published.
