# Manager Board v2.7.1 — Workfront Intake Import Repair

This patch fixes the file-selection error that could block Workfront Intake import after the workbook preview reported that it was ready.

## Fixed

- Removes Save draft, Discard draft, and unfinished-draft recovery from the Workfront Intake import view.
- Keeps the selected workbook available through validation and import, preventing the misleading “Please select a file” error.
- Clears the intake selection when the dialog is closed or cancelled. Reopening starts a fresh import.

Other editor drafts and Workfront import workflows retain their existing behavior. Project imports continue to stage local records for review before publishing to Workfront. Schema remains 48. User data and optional Local AI models remain separate from application binaries.
