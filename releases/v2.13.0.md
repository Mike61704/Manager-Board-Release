# Manager Board v2.13.0 — Project Teams, Priority and Task Hierarchy

Projects now follows the Home Teams configured in Workfront Connections, and task lists can match Workfront's numbered parent/subtask order.

- **Home Team filtering:** select one or more verified Connections Home Teams. Counts, existing filters and current-view exports share the same project population. All Teams removes the Team restriction and includes projects without Team metadata.
- **Offline team visibility:** configured names remain visible offline, including older Connections settings. A team without a cached Workfront Team ID shows “Team ID not cached”; filtering becomes available after its identity and associations are synced. Once cached, an active connection is not required each time.
- **Edit Team Priority:** change or clear IT Team Priority in Edit Project. Existing linked-project changes are saved locally, then published through Review & Publish with conflict checks and confirmation. Discard restores the saved baseline. This uses the custom IT Team Priority field, separate from standard Workfront Project Priority.
- **Task numbering and hierarchy:** view actual Workfront task numbers and choose Workfront Task Number sorting. Subtasks follow their real parents with slight indentation. Numbers use a subtle neutral outline. Current-view task exports include the number; parent context does not inflate filtered record counts.

Existing Projects, publishing/discard safeguards, exports, themes, appearance, licensing, Employee Plans, Local AI and Workspace/Vault continuity are preserved. Schema 48 is unchanged. Local AI models remain separate.

New-project custom-priority creation is not added. Workfront publishing requires the user's authorized connection and tenant access to the custom field.
