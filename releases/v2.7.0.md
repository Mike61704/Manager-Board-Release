# Manager Board v2.7.0 — Manager Preparation and Draft Recovery

This release adds AI-assisted preparation for your own manager 1:1 and improves Daily Work entry and unfinished-draft recovery.

## New and improved

- Generate rich, first-person manager 1:1 suggestions using Manager Work, notes, reflections, employee 1:1 context and previous manager meetings.
- Choose the activity period and review source references before adding suggestions to your preparation.
- Recap team themes and decision questions while preserving who owns recorded commitments. Proposed director follow-ups are clearly labelled for confirmation.
- Recover automatically when a local model returns an unreadable source selection during a larger history review.
- Resume unfinished drafts from a compact soft-orange notice. Draft recovery is optional and never blocks new input.
- Type manual Daily Work as bullets and paste clean bullets without source styling. Imported work keeps its existing formatting.
- Add Daily Work contributions while preserving earlier work, attachments and confirmed counts, with a clear confirmed Delete action.

Employee AI summaries retain their existing behavior. Suggestions remain editable and are never inserted or saved automatically. Settings are excluded from draft capture. Schema remains 48; Workspace/Vault separation and privacy boundaries remain intact. Local AI models are optional, separate and not bundled.

## Validation

The product owner accepted desktop source smoke testing, including manager AI preparation and draft recovery. The complete regression suite passed 2,729 tests. The supported release pipeline passed its package and real-model quality gates and verified trusted application, native runtime, embedded installer and uninstaller signatures. Installed runtime, signature and desktop smoke checks passed. User data and optional model files remain separate from the application.
