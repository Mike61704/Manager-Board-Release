# Manager Board v2.0.64 — Update Center Corrections

Manager Board’s update center is now more direct and predictable. Review Update takes you to the right place, and upgrades start with the newest trusted release selected. ✨

## What’s new

- Review Update now opens Settings > About / Version and scrolls directly to Application Updates.
- Newly discovered manual upgrades default to the newest available signed public release.
- An older supported release remains selected only after you explicitly choose it during the current session.
- Background PowerShell signature checks stay hidden during the upgrade path.
- The Manager Board-themed installation window and its real measured progress remain visible while the installer is working.

## Still true

- Downloaded installers must match the official repository, versioned filename, byte count, GitHub SHA-256 digest, HTTPS release path, and trusted Authenticode publisher before installation.
- Manager Board releases its protected Workspace and Vault session before starting an update.
- Offline device-bound activation remains valid across normal updates on the same Windows profile.
- Automatic installation remains off until the user chooses a schedule.
- The core workspace remains local-first.
- Schema v41, Workfront safety, Local AI isolation, backup/restore, session privacy, and Workspace/Vault protections are unchanged.
- No source code, private signing material, organization data, user data, or GGUF model is included.
