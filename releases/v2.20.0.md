# Manager Board v2.20.0 — Flexible Repeats and Calendar Notices

- **Repeat Manager Work your way:** choose Daily, Every weekday, or Custom. Set an interval in days, weeks, months or years; weekly schedules can select specific weekdays. Complete, skip or end a series using the established Manager Center workflow.
- **Keep calendar-only reminders:** use Calendar > Add Calendar Notice, or Add Calendar Notice on a selected day, for items such as in-office work days. Choose a single date, weekly, every two weeks, monthly or a custom schedule without creating a task, Follow-up or daily note.
- **Manage a notice series:** edit the whole series, remove one date, or delete the series after confirmation. Unfinished changes use the normal saved-draft recovery workflow.

Calendar Notices are local, all-day calendar entries. They do not send timed popup or background alerts. Every weekday excludes weekends, not holidays. Custom month/year schedules retain their original anchor day. Saving a notice edits the whole series, including previously displayed dates; removed dates remain excluded.

This update advances the data format to schema 51. The normal portable backup runs before upgrading an older Workspace. Keep that validated backup if you need to return to an earlier application: an application downgrade does not downgrade data. Existing notes, employee plans, completed 1:1 history, attachments and Follow-ups remain preserved. Application updates keep Workspace data and activation separate from the replaceable application files. Optional Local AI models remain separate downloads.

## Try it

Open Manager Center, add or edit Manager Work, and choose a Repeat option. For calendar-only planning, open Calendar and choose Add Calendar Notice. Saved notices appear on matching dates and have their own calendar filter.
