# Manager Board v2.9.4 — License Trust and Workfront Intake

Review license verification keys, recover from key-related activation failures, and import employee intake worksheets with clearer guidance.

- **Settings > Security** shows configured public-key IDs, fingerprints, and the active license's verification status.
- **License Security & Diagnostics** is available from activation before the Workspace opens. It accepts an owner-signed `.mbkey` rotation file, preserves existing trusted keys, and still requires a valid device-bound license before opening Manager Board. Obtain rotation files from the license publisher; an ordinary public-key PEM cannot authorize an installed application.
- Worksheet intake retains assignees outside your Manager Board roster without creating People records or blocking import. Workfront assignments still require the person's actual Workfront identity before publishing.
- Conflicting intake task numbers identify the incoming and existing tasks and suggest the next available number. Existing projects must use unused task numbers; import does not silently renumber or overwrite existing tasks.
- The employee intake template explains external assignees and numbering for existing projects. Use **Revise Project** to change existing tasks.
- Browser sign-in cancellation now releases the connection attempt so users can retry.
- Includes the connection diagnostics from the 2.9.3 development branch. Legacy Workfront sign-in remains the default. Adobe Native authentication remains under investigation and this release does not resolve that issue.

Schema 48 is unchanged. The installer retains activation and Workspace data. Optional Local AI models remain separate. The private licensing generator is distributed separately by the publisher.
