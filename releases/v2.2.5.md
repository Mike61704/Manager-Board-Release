# Manager Board v2.2.5 — Daily Work Scoring Reliability

Manager Board now counts Daily Work consistently whether work is entered as
formatted bullets, separate plain lines, a combined narrative, or pasted notes.

## What’s improved

- Counts top-level bullets and separate non-empty lines as individual work
  items without requiring every manager to format notes the same way.
- Shows the detected manual work-item count before saving.
- Adds an optional manager-confirmed total when one paragraph or bullet contains
  multiple distinct activities, without silently counting ordinary sentences as
  extra work.
- Uses the confirmed count consistently for Auto Impact, Daily Work cards,
  Calendar, reports, Employee Accomplishments, and Leaderboard scoring.
- Starts new Daily Work entries with a clean bullet and does not save an
  untouched placeholder.
- Converts pasted Work Performed notes into clean bullets after removing source
  formatting and duplicate bullet, dash, star, or number markers.

## Safety and continuity

- Existing Daily Work records remain compatible.
- Nested bullets remain supporting detail rather than separate scored work.
- Schema remains v45; no database migration is required.
- Existing Workspace, Vault, Workfront, activation, backup, restore, Local AI,
  updater, and privacy boundaries remain intact.
- No GGUF model, source code, business data, credentials, or private signing
  material is included in this release repository.
