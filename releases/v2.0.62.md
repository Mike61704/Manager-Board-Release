# Manager Board v2.0.62 — About Experience Refinements

Manager Board’s About page is cleaner, more useful, and easier to scan—while keeping the signed update path and offline activation protections introduced in v2.0.61. ✨

## What’s new

- The installed Manager Board version now appears directly in the main About hero.
- The redundant Current Version, Storage Model, and Network Use row has been removed.
- The newest two release summaries now live in one collapsed **Latest version changes** section, ready when you want the details without crowding the page.
- The About layout is protected by focused source and runtime regression checks so the accepted hero, license, update, and release-history order cannot silently fall back to legacy content.
- This release is the first public end-to-end validation of Manager Board’s signed in-app upgrade path from v2.0.61.

## Still true

- Offline device-bound activation remains valid across normal updates on the same Windows profile.
- Automatic installation remains off until the user chooses a schedule.
- The core workspace remains local-first.
- Schema v41, Workfront safety, Local AI isolation, backup/restore, session privacy, and Workspace/Vault protections are unchanged.
- No source code, private signing material, organization data, user data, or GGUF model is included.
