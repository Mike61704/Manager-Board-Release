# Manager Board v2.1.0 — Help and Guided Local AI

Manager Board now brings the instruction manual with it—right where the work happens. Open Help from the screen you are using and get focused, offline guidance without leaving the application. 🧭✨

## What’s new

- Adds one accessible, context-aware **Help** window across startup, the main application, Settings, employee 1:1s, Employee Plans, and nested workflows.
- Includes **57 reviewed, organization-neutral Help topics** with clear steps, visible control names, expected results, and safety notes.
- Opens the most relevant topic for the current screen or dialog while keeping search, browse-all, related topics, and back navigation in the same window.
- Keeps entered form and workflow state in place while Help is open.
- Supports keyboard access, responsive layouts, light and dark themes, and direct Help access without opening Chat.

## Guided Local AI

- Optional Local AI can ground Manager Board product answers in the same approved Help library.
- Help-grounded answers can explain choices and next steps naturally instead of reciting an entire topic.
- General management guidance is clearly separated from verified Manager Board behavior.
- **General Chat remains separate** and does not silently turn into product Help.
- Manager Board continues to work normally when Local AI is disabled or no model is installed.

## Privacy and continuity

- Built-in Help works offline and requires no AI, internet connection, account, server, Workspace, Vault, or database access.
- Help content is read-only and does not search employee records, files, attachments, or manager identity.
- Schema v41 is unchanged.
- Offline activation, secure updates, Workfront safety, Local AI isolation, backups, restore, session privacy, project synchronization, and every accepted Workspace/Vault boundary remain intact.
- The complete CPU, Vulkan, OpenVINO Intel NPU, and TBB runtime remains included.
- No source code, private signing material, organization data, user data, or GGUF model is included.
