# Manager Board v2.6.2 — Settings Connection Repair

This maintenance update removes draft handling from configuration screens and restores the normal Workfront connection path.

## Fixes

- Settings use their normal Save and action controls without draft recovery toolbars or draft-storage dependencies.
- Workfront Connect can save configuration and initiate sign-in even when draft storage is unavailable.
- Local AI, Manager Profile, weather and meeting configuration, archive setup, alias selections, folder naming, and career-path setup no longer create recovery drafts.
- Starting a manager 1:1 saves its settings and creates the meeting together without requiring a configuration draft.
- Notes, work records, 1:1 narratives, and other supported data-entry editors retain draft recovery.
- Help and Close sit together in the Unfinished drafts window.

Existing configuration draft contents are retained without deletion but are excluded from the recovery list. Schema remains 48 with no new migration. Workspace/Vault separation, privacy boundaries, and narrative draft timing are unchanged. Optional Local AI models remain separate and are not bundled.

## Validation

All 2,635 regression tests, 109 package checks, and 20 real-model quality cases passed. Trusted application, runtime, embedded installer, uninstaller, and final installer signing passed. A fresh public download matched the published size and SHA-256 digest. The normal Windows installation returned success; all 33 installed signatures and the packaged runtime check passed.

Installed Test Workspace smoke verified clean Workfront and Local AI headers, an enabled Connect control, ordinary Manager Profile Save, grouped Help/Close buttons, and an existing employee 1:1 recovery entry. The focused Workfront test verifies sign-in dispatch with unavailable draft storage using isolated data and a stubbed authentication endpoint. Live account authentication remains a user action.
