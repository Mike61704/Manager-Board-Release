# Manager Board v2.10.3 — Complete Wins and Reliable AI

This update brings complete employee recognition, responsive AI startup, and consistent private 1:1 preparation together in one public release.

- **Wins & Recognition** includes every eligible recorded win in the employee 1:1 evidence window as dated, editable bullets. Older certifications remain included alongside newer activity. Review or remove bullets before inserting and saving.
- **Employee History** displays all wins in its preparation window.
- **Background Local AI startup** keeps Manager Board responsive while configured model checks and initialization run. The existing **Local AI is ready** notification appears when loading completes.
- **Private 1:1 preparation** includes Manager Preparation, Topics to Discuss, and Private Observations / Concerns. Useful AI prose stays intact. Supported fields omitted by the model receive editable, cited **Source-based drafts** without extra generation passes. Observations require recorded evidence; ordinary work and wins do not create concerns. Private suggestions remain excluded from shared previews and exports.

Existing Adobe Native sign-in, license security, Workfront Intake protections, activation and storage behavior are retained. Schema 48 is unchanged. Workspace, Vault and recovery data remain separate from application binaries. No Local AI model is bundled or downloaded.

Release validation: 2,917 regression tests, 109 package checks and 20/20 accepted-model quality cases passed. Native desktop, compiled-payload, runtime and required signing checks passed. Five established test warnings; no test failures. Separate human installed/live acceptance is not claimed.
