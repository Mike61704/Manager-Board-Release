# Manager Board v2.1.1 — A Guided First Start

Manager Board now welcomes new users with a focused setup guide that explains the first decisions clearly and gets them into a working board with confidence.

## What’s new

- Adds a guided welcome experience for first-time startup.
- Explains the available startup paths before the user chooses how to begin.
- Guides users through creating a new Manager Board or activating an existing installation.
- Keeps startup choices clear, reversible where appropriate, and consistent with the built-in Help experience.
- Adds focused Help topics for the welcome guide, startup options, board creation, and activation.

## Privacy and continuity

- The welcome flow works locally and does not require an online account.
- Existing Manager Board users continue directly into their established workspace.
- Offline activation, secure updates, Workfront safety, Local AI isolation, backups, restore, session privacy, and Workspace/Vault boundaries remain intact.
- The complete CPU, Vulkan, OpenVINO Intel NPU, and TBB runtime remains included.
- No source code, private signing material, organization data, user data, or GGUF model is included.
