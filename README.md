# Manager Board Releases

Public repository reserved for future activation-gated, Microsoft-signed Manager Board Windows releases and update metadata.

The Manager Board source code is maintained privately and is not published in this repository.

## Current status

No installers or GitHub Releases are published yet. The release channel will remain empty until device-bound offline activation is implemented and accepted.

Future release assets must contain no Manager Board Workspace, Vault, Workfront session, signing credential, GGUF model, employee data, or RBFCU data.
